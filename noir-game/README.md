# NOIR: DOSYA 01

## Kayıp Saatler

PC ve mobil için responsive, tek sayfalık oynanabilir dedektiflik prototipi.

### İçerik
- Olay yeri taraması ve etkileşimli kanıt noktaları
- Kanıt arşivi
- Zaman çizelgesi
- Şüpheli sorgulama
- Oyun içi telefon mesajları
- Teori panosu
- Dedektif notları ve cihaz içi kayıt
- Mobil uyumlu arayüz

### GitHub Pages
Bu prototip ek bağımlılık gerektirmez. GitHub Pages kaynağı olarak `noir-game` dalını kullanmak yerine bu dalı Pages için yayınlamak gerekir; daha temiz bir kurulum için ileride oyunu ayrı bir repository'ye taşıyabiliriz.
